# GigGuard

AI-Powered Parametric Insurance for India's Gig Economy

## Problem
Delivery workers lose income when weather, pollution, or restrictions stop orders.

## Solution
A parametric insurance workflow that uses verified external triggers and auto-starts claims.

## Project Structure
- `frontend/`: React + Vite dashboard
- `backend/`: FastAPI backend for triggers and enrollments
- `ml-models/`: Placeholder ML scripts
- `docs/`: Additional documentation
